# 窗口布局启动器 v2.1.0 正式发布说明 (WindowLayoutLauncher)

> **版本**：`v2.1.0`  
> **发布日期**：2026-10-01  
> **适用平台**：Windows 10 / 11 (x64 / x86)  
> **交付物**：`WindowLayoutLauncher-v2.1.0-windows-x64.zip` (绿色便携，50 KB)  

---

## 🎯 核心解决痛点

多显示器、多窗口工作流切换（如开发模式、复盘模式、监控模式）时，频繁手动拉伸对齐窗口效率低下。窗口布局启动器支持**一键捕捉当前屏幕上所有窗口的精确位置与尺寸**，保存为特定方案，下次点击**一键毫秒级物理复原**。

---

## 🚀 v2.1.0 核心更新亮点

1. **新增程序内“日志与诊断”查看器**：
   - GUI 内置一键查看恢复日志、崩溃日志与更新诊断，方便排查未成功复原的特殊窗口；
2. **毫秒级恢复日志防覆盖**：
   - 恢复日志命名精确至毫秒，补充结构化应用事件流，消除快速连点时的日志被冲毁问题；
3. **后台异步静默更新检查与下载**：
   - 更新检查完全移至后台工作线程，弱网或网络抖动时不卡死前台 UI；
4. **安全升级三重防护门禁**：
   - 增加正式 GitHub Releases 域名合法性校验；
   - 增加 PE/MZ 标头合法性校验；
   - 增加 SHA-256 完整性核销校验，替换前自动创建带时间戳的当前版本备份；若更新失败自动回滚；
5. **极简便携，开箱即用**：
   - 纯 C# WinForms 原生编译，单文件仅 90 KB，零外部臃肿依赖。
